# musicsort — двуязычная документация

`README.md` в этом проекте ведётся **на двух языках**: русская секция (якорь `#ru`) и английская секция (якорь `#en`), разделитель `* * *` между ними.

## Правила при любом изменении документации

1. **Всегда зеркаль.** Каждое содержательное изменение (новая фича, изменение команды/флага, новые результаты прогона, тайминги, предупреждения) вносится в ОБОЕ секции: русскую и английскую, с равной деталью. Одноязычная правка — incomplete работа.
2. **Команды и флаги не переводить.** CLI-команды, имена файлов, параметры (`--yes`, `--fill-from-log`), имена констант и пути остаются как в коде в обеих секциях. Переводятся только пояснения.
3. **Переключатель языков поддерживается.** В самом верху файла и в начале английской секции должна оставаться строка навигации:
   `[🇷🇺 Русский](#ru) · [🇬🇧 English](#en)`
   с анкерами `<a id="ru"></a>` и `<a id="en"></a>`. Не удалять и не переименовывать их.
4. **Структура секций идентична.** Одни и те же заголовки/порядок разделов в обоих языках (Installation/Установка, Just sort it/Просто отсортировать, Labeling/Разметка, Retraining/Переобучение, Notes/Примечания и т.д.), чтобы по заголовку одной секции находилось место в другой.
5. **Примеры вывода** (логи прогонов, числа placements) фиксятся к актуальному прогону и обновляются в обеих секциях одновременно.

## Типичные запросы

- «обнови/дополни документацию» → правишь обе секции; сверяешь по этому списку.
- «добавь английскую/русскую версию» → если языка нет — добавь недостающую секцию по структуре другой.
- Быстрая самопроверка после правки: заголовки секций совпадают по смыслу 1:1; переключатель на месте; нет контента, существующего только в одном языке.
